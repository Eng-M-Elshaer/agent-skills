# Agent Skills

A collection of Codex skills copied from the local `~/.codex/skills` directory. Each skill keeps its complete source bundle, including `SKILL.md`, references, scripts, assets, tests, and any embedded license files.

## Mobile development skills

An overview of the repository's mobile-focused skills for Flutter, Android, iOS/SwiftUI, and Firebase. The video also labels `mobile-cross-platform-designer` as coming from the attached ZIP; that skill is not currently in this repository.

[![Watch the mobile development skills video](https://img.youtube.com/vi/wqkoR8TsEas/hqdefault.jpg)](https://youtube.com/shorts/wqkoR8TsEas)

## Installation

Copy the skill directories you need into your Codex skills directory:

```sh
cp -R skills/<skill-name> ~/.codex/skills/
```

Read each skill's `README.md` for a concise guide and its `SKILL.md` for the complete instructions.
