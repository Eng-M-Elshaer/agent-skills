# my-project-rules

Create or update repo-local project rules for a new or existing project. Use when setting up a project for the user's default workflow, creating or refreshing AGENTS.md, enforcing persistent project memory, selecting relevant skills automatically by project type, or onboarding Codex into a repository before implementation work.

## Activation

Use this skill when the request matches the trigger and scope described in `SKILL.md`.

## Prerequisites

Read `SKILL.md` before use. Any tool, runtime, connector, or project requirements are documented there.

## Contents

- `SKILL.md`
- `agents/`
- `scripts/`

## Usage

Copy this directory into your Codex skills directory, then invoke the skill by its name when the request matches its scope. `SKILL.md` is the authoritative specification.
