# divide-and-conquer

Use this skill for any engineering or problem-solving task that involves complexity, ambiguity, or multiple moving parts. Triggers include: debugging hard bugs, designing system architecture, refactoring large codebases, implementing multi-step features, planning sprints or technical tasks, or any time the user says "I don't know where to start" or "this is too complex". Also use when reviewing code, designing APIs, breaking down user stories, or solving algorithmic challenges. ALWAYS use this skill before jumping to a solution — decompose first, solve second. Works across iOS (UIKit/SwiftUI), Android (Kotlin/Jetpack Compose), Flutter, and general software engineering tasks.
