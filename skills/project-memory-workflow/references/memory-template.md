# قالب ذاكرة مشروع

آخر تحديث: YYYY-MM-DD
النطاق: هذا الملف يوثّق فقط هذا الريبو.

## تعريف المشروع
- ما هو المشروع؟
- ما المشكلة التي يحلها؟
- أي أسماء منتج / branding تؤثر على الكود أو UX؟

## الحالة الحالية
- نقطة الدخول
- الفلو الأساسي الحالي
- auth / onboarding / navigation / persistence / network
- أي behaviors مهمة يجب أن يعرفها أي agent قبل التعديل

## المعمارية والملفات المحورية
- طبقات المشروع الأساسية
- الملفات أو modules المرجعية
- أدوات البناء أو dependency managers المهمة

## قرارات ثابتة
- قواعد يجب ألا تتغير بسهولة
- conventions خاصة بالrepo
- ما الذي يُعامل كمصدر الحقيقة؟

## سجل التغييرات
- YYYY-MM-DD: عنوان مختصر
  - ما الذي تغيّر؟
  - هل ما زال قائمًا أم تم استبداله لاحقًا؟

## Open Questions / نقاط تحتاج متابعة
- نقاط لم تُحسم بعد
- تناقضات naming / API / product تحتاج قرارًا لاحقًا
