# ios-security-audit

Audit iOS Swift applications for banking-grade mobile security risks and generate a clear PDF security audit report. Use when reviewing Swift source, Info.plist, entitlements, Podfile/Package.swift, or Xcode configuration for issues in sensitive storage, network hardening, auth controls, API safety, jailbreak detection, reverse engineering resistance, privacy permissions, and sensitive UI protection.
