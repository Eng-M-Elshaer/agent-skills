# flutter-architecture-reviewer

Review a Flutter/Dart project for Clean Architecture compliance with a core/ + features/ structure. Use when you need an architecture audit report covering structure/layering, dependency rule violations (UI→Logic→Data only), naming conventions, file size hotspots, networking/routing/state-management smells, reusability/duplication hints, and a scored, actionable refactor plan in Markdown (exportable to PDF).

Use this skill when the request matches the trigger and scope described in `SKILL.md`.
