# Flutter Architecture Rules (Reference)

Use this as the reference baseline for the report generated by `scripts/analyze_flutter_arch.py`.

## Structure

```text
lib/
└── core/
    ├── di/
    ├── networking/
    ├── routing/
    ├── helpers/
    ├── theming/
    └── widgets/
```

```text
lib/
└── features/
    └── feature_name/
        ├── data/
        │   ├── models/
        │   ├── repos/
        │   └── data_sources/
        ├── logic/
        │   ├── cubit/
        │   └── state/
        └── ui/
            ├── screens/
            └── widgets/
```

## Dependency Rules

Allowed:

```text
UI -> Logic -> Data
```

Not allowed:

```text
Data -> UI
Logic -> UI
Core -> Feature
Feature -> Another Feature (direct imports)
```

## File size warnings (default)

- Screen > 500 lines
- Cubit > 300 lines
- Widget > 250 lines
- Repository > 400 lines
