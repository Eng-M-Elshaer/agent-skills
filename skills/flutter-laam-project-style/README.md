# flutter-laam-project-style

Best practices and coding style for Flutter apps following the Laam For Parents project architecture. Use this skill whenever working on any Flutter feature, screen, Cubit, repository, model, widget, or configuration in a project that follows Clean Architecture + BLoC/Cubit + Freezed + Dio + GetIt. Trigger this skill for: creating new features, writing Cubits, setting up flavours, error handling, responsive UI, API integration, or reviewing/refactoring Flutter code. Even if the user doesn't mention "Laam" explicitly — if the task involves Flutter + Clean Architecture, use this skill.
